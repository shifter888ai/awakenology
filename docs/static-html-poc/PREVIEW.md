# Build-time HTML migration — preview

> **Review preview only.** This document describes the shared page chrome generated by the isolated prototype in PR #521. It is not a deployed website, and it does not change the live Awakenology site.

## What the generated page chrome looks like

The prototype replaces each source page's global header and footer with two shared HTML templates:

- [Header template](../../scripts/static_html_poc/assets/header.html)
- [Footer template](../../scripts/static_html_poc/assets/footer.html)

### Header

```text
╭────────────────────────────────────────────────────────────────╮
│  Ⓐ  Awakenology       English   日本語   中文   │   Search  Ask  Links │
╰────────────────────────────────────────────────────────────────╯
```

- The circled-A brand links to the homepage.
- Language links lead to the English, Japanese and Chinese sections.
- Search, Ask and Links are compact icon links.
- The active language or action is marked for the current route.
- The same template is reused across generated public HTML pages.

### Footer

```text
──────────────────────────────────────────────────────────────────
             Contact   Reddit   Reddit   Reddit   Disclaimer
                       © 2017–2026 Awakenology
```

- Contact and Disclaimer receive the current-page state on their respective pages.
- The three existing Reddit destinations and icons are retained.
- The copyright year is populated during generation.

## Route-specific active states

| Page route | Active header state |
|---|---|
| `/English/` | English |
| `/Japanese/` | 日本語 |
| `/Chinese/` and `/Coach_cn/` | 中文 |
| `/search/` and legacy `/ai-search/` | Search |
| `/ask/` | Ask |
| `/links/` | Links |

The prototype also applies the existing theme, Chinese text conversion, favicon, page classification and SEO metadata transformations. These remain build-time transformations; the header/footer templates do not replace the Worker’s dynamic responsibilities.

## What has been validated so far

- 29 prototype unit tests passed in the previous completed parity job.
- Nine pinned real-page fixtures passed source/content, image, metadata, deterministic-output and idempotence checks.
- The generated header/footer signature matched the live Worker output in the completed parity job.
- The public inventory contained 144 eligible HTML routes; the temporary staging generator produced 144 pages.
- Internal, draft and editor/tooling HTML is excluded from the public inventory.

A subsequent runtime-contract check found that its Search-page assertion was outdated. That assertion has been corrected in the branch; a fresh run is still required. Desktop/mobile browser parity was still running at the last check.

## What this preview does not claim

- It is not a live preview URL or a production deployment.
- The current staging prototype generates HTML in a temporary directory and deletes it after validation; it does not yet package the complete static site and its assets.
- Cloudflare routing, Worker behavior, private Editor authentication, Contact API and publishing endpoints have not been changed.
- No production switch is authorized or included.
